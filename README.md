# Module 05.2 - Advanced Prompting: Roles, Examples & Iterative Refinement

An interactive, web-based presentation designed for the **Foundation Diploma in Digital Technology, AI & Future Skills**. This module introduces advanced prompt engineering techniques to sculpt AI behavior, control tone, and guarantee format consistency.

## 🎯 Learning Objectives
This presentation moves beyond basic prompting to teach students how to generate production-ready AI outputs using three core pillars:
* **Role Prompting (The Persona):** Forcing the AI to adopt a specific perspective, vocabulary, and expertise level.
* **Few-Shot Prompting (The Pattern):** Using contextual input-output examples to establish strict formatting rules (e.g., JSON schemas).
* **Iterative Refinement (The Sculptor Approach):** The process of treating initial outputs as drafts and systematically critiquing, correcting, and polishing them across multiple chat turns.

## ✨ Features
* **Interactive UI:** Clickable, multi-turn chat simulations demonstrating the iterative refinement cycle.
* **Live Concept Demos:** Visual comparisons of Zero-Shot vs. Few-Shot prompting outputs.
* **The Sculptor Analogy:** A visual breakdown of how tasks, contexts, constraints, and formats shape raw AI intelligence into a masterpiece.
* **Zero Dependencies:** Built entirely with pure HTML, CSS, and vanilla JavaScript.
* **Fully Responsive:** Adapts smoothly across different screen sizes and classroom projectors.
